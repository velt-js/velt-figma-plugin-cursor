# Primitive capability coverage

Generated by `node scripts/audit-primitive-capabilities.js --markdown`.

**What this table does and does not prove.** It proves every V2 primitive supports every capability
required of it. It does NOT prove a zero-wireframe build is possible — that additionally needs a
primitive to EXIST wherever a wireframe slot can reach — and **392 of 770 wireframe slots still have
no primitive counterpart** (recorder, V1 comment surfaces, cursor/presence/reaction/live-state-sync),
so a wireframe remains mandatory for those positions. That measurement is recorded in
`docs/primitives-gates.md` §3; it is not gated. The two answer different questions — do not read this
table as "primitives can do everything".

`R2 consume` is scored only where it applies — a primitive that resolves an entity from an id/index/
selector. Presentational leaves have nothing to inherit and are excluded rather than counted as gaps.
