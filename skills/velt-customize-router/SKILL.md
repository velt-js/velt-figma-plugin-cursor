Route a customization task to the guide. **Always run the decision tree first.**

1. Read `guide/README.md` ("How to use this guide") for the canonical reading order.
2. Run `guide/02-decision-tree.md` against the design to pick the layer(s) per surface.
3. Hand off: an ordered reading list + the chosen layer hint → then the layer-specific skill (`velt-css` / `velt-wireframes` / `velt-primitives`), `velt-reference`, `velt-rules`, `velt-verify`.

Carry no knowledge of your own — point at `guide/` and apply it.
