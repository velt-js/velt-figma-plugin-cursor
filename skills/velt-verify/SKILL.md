name: velt-verify
description: Verify a finished Velt surface against the design — drive states, confirm behavior, run the rules scan, emit a verdict. Use after building each surface (R15/R16).
---

Verification flow → verdict. **Measure the WHOLE surface, don't eyeball or sample.**

- **STRICT — verify the app URL BEFORE measuring anything: never assume the dev server is on `localhost:3000`.** The port is run-specific (dev servers auto-bump when 3000 is taken; projects override it; another project's server may be squatting there). Use the **pinned `appUrl` from the run journal**; if none is pinned, resolve it from the dev server's own startup output (or enumerate listening ports and probe) and **confirm the responder is THIS app** (expected title/route/`velt-*` elements) before any capture/probe. Wrong-URL evidence is void — measuring a different app/port is a silent false verdict, and an unreachable pinned URL is **BLOCKED**, not FAIL.
- Follow `guide/verifying-a-customization.md` step for step: drive **every** state → whole-surface **measured** delta check + a **mandatory visual side-by-side** → behavior check → static rules scan against `guide/rules.md`. Cross-cutting (a11y/dark/RTL/responsive): `guide/cross-cutting.md`. Stuck? `guide/debugging.md`.
- **Coverage is GENERATED, not authored — the oracle is `blocks.json`** (`scripts/enumerate-blocks.mjs`: every Figma frame/state is a block, `Flows` + `State`). For the current block measure **every** mapped element (every distinct styled appearance + every `mustSupply` + every contract part). You do NOT author a narrower spec. Inject `BROWSER_PROBE` from `scripts/delta-compare.mjs` `{surfaceSelector, tol, elements, relations, gaps}`; it diffs live `getComputedStyle` (style: ΔE<2, ±1px) AND surface-relative `getBoundingClientRect` (layout: box/gap/relation/missing). Write the block's disposition into `block-report.json`; `scripts/verdict-gate-blocks.mjs` decides done — **a run missing a block / undriven state / artifact is INCOMPLETE, never PASS** (R26).
- **Gross-mismatch pre-check first** (total height / element count / extents) — a grossly-off surface FAILs before per-element work.
- **Visual gate is a GATE:** full-surface screenshot beside the Figma frame; **name every visible difference**; any nameable diff ⇒ FAIL.
- **Layer reconciliation (R22/R23):** for each painted node inject `LAYER_PROBE` (`scripts/delta-compare.mjs`) — FAIL on `ownerMismatch` (styled the wrong layer; the box doesn't match the design node — general R23) or any `neutralize[]` entry (a co-box wrapper still paints padding/bg/border the design applies once — general R22). It inspects box-painting only, never functional CSS.
- **Mount-map contract (R25) — the functional veto:** run `CONTRACT_PROBE` on the post-reconciliation DOM against the manifest's `contract.parts` — FAIL on any `MISSING`/`CONTAINMENT`/`CARDINALITY`/`PHANTOM_INTERACTIVE`. A boolean veto: a pixel-perfect surface with a broken mount map (absent primitive, hoisted-out-of-context part, duplicated singleton, custom control the SDK doesn't own) is a hard FAIL.
- **Interaction stability (R27) — the transition veto:** static captures don't catch a control that *moves during the click*. For **every interactive affordance** the surface renders (the same set the phantom scan walks) inject `STABILITY_PROBE` (`scripts/delta-compare.mjs`) — it measures the target's box, drops the transient state the click drops (blurs the focused element), reflows, re-measures. **Any shift > 1px ⇒ FAIL** (a rule keyed on `:focus`/`:hover`/`:active` instead of a stable, persistent open/selected state). Then perform the primary action **end-to-end** (do the interaction → real-click the visible control → confirm the outcome); one nearby path passing is not proof. PASS = visual ∧ layout ∧ contract ∧ stability.
- **Hard gates:** console error / unbuilt / `width===0` ⇒ BLOCKED/FAIL; every `mustSupply` slot ([`guide/reference/manifest.md`](../../guide/reference/manifest.md)) present + carrying the design's SVG/content (R17); no feature whose UI the design lacks (R24). **No aggregate score** — a goal is `met` only when style + layout deltas are empty for that state AND no nameable visual diff, with evidence; "looks close" or "5 props pass" is a FAIL. Verdict: `PASS | PARTIAL | FAIL | BLOCKED`. The verifier never declares the RUN done — it surfaces evidence + writes `block-report.json`; the mechanical `verdict-gate-blocks.mjs` exit code terminates, never `/goal`. Unmet-but-no-clean-path → `velt-gap`.
